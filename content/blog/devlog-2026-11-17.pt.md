## Segurança e DevOps em Produção

Qualquer automação corporativa necessita de uma camada de infraestrutura zero-trust:

- **Firewall UFW Rígido:** Bloqueio padrão de entrada, liberando apenas portas essenciais (22, 80 e 443 TCP/UDP).
- **Prevenção de Intrusões com Fail2ban:** Jails ativas para mitigar ataques em SSH e autenticação de contêineres.
- **Caddy com HTTP/3 & QUIC:** Certificados TLS automáticos e alta performance de transporte para clientes modernos.
- **Backups Criptografados no Telegram:** Snapshots de bancos de dados enviados de forma programada e segura para um canal privado via bot.


## Validação Estruturada com Zod

Garantimos a integridade de cada registro antes da persistência no banco de dados com esquemas tipados:

```typescript
import { z } from 'zod';

export const B2BProspectSchema = z.object({
  name: z.string().min(2),
  category: z.literal('Firmas Legales & Contables'),
  country: z.string(),
  city: z.string(),
  website: z.string().url(),
  phone: z.string().optional(),
  instagram: z.string().optional(),
});

export type B2BProspect = z.infer<typeof B2BProspectSchema>;

export async function ingestProspects(rawJson: unknown[]): Promise<B2BProspect[]> {
  return z.array(B2BProspectSchema).parse(rawJson);
}
```
