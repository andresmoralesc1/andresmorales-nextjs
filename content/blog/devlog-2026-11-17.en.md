## Production DevOps & Server Hardening

No automation workflow is reliable without a zero-trust host foundation:

- **Strict UFW Firewall:** Enforced default drop policy (`DROP`), strictly exposing only ports 22, 80, and 443 (both TCP and UDP for QUIC).
- **Fail2ban Intrusion Prevention:** Active jails monitoring SSH brute force and containerized authentication endpoints.
- **Caddy HTTP/3 + Auto TLS 1.3:** Seamless zero-maintenance TLS certificates paired with QUIC transport for ultra-low latency.
- **Encrypted Telegram Backup Vault:** Automated periodic database dumps encrypted and piped directly to an isolated, private Telegram channel via authenticated bot APIs.

## Strict Schema Validation for Ingestion

To ensure consistency across CRM ingestion pipelines, every payload is validated at runtime before hitting persistent storage:

```typescript
import { z } from 'zod';

export const B2BProspectSchema = z.object({
  name: z.string().min(2),
  category: z.literal('Firmas Legales & Contables'),
  country: z.string(),
  city: z.string(),
  website: z.string().url(),
  phone: z.string().optional(),
  instagram: z.string().optional(),
});

export type B2BProspect = z.infer<typeof B2BProspectSchema>;

export async function ingestProspects(rawJson: unknown[]): Promise<B2BProspect[]> {
  return z.array(B2BProspectSchema).parse(rawJson);
}
```
