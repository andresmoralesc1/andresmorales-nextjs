No desenvolvimento web moderno, a diferença entre uma experiência instantânea e a perda de um usuário é medida em milissegundos e kilobytes redundantes. Na jornada de hoje, realizamos uma auditoria profunda de Core Web Vitals no **¡Qué Nivel, Maribel!** (nossa plataforma de ticketing e CRM), expandimos ferramentas de eventos compartilháveis para o El Gato Colectivo e fortalecemos a infraestrutura de produção.

### O Desafio Técnico: Polyfills Desnecessários e Bloqueio de Renderização

Ao analisar diagnósticos do Chrome DevTools no `quenivelmaribel.com`, identificamos dois grandes obstáculos que impactavam o LCP e a thread principal:

1. **JavaScript Legado em Excesso (~14 KiB)**: O bundle continuava incluindo polyfills para recursos nativos como `Array.prototype.at`, `Array.prototype.flat`, `Object.fromEntries` e `Object.hasOwn`.
2. **Atraso na Descoberta do LCP**: O elemento visual principal do hero sofria atrasos devido a preloads concorrentes e carregamento antecipado de formulários complexos.

```typescript
// next.config.js - Configuração para target ES2022
/** @type {import('next').NextConfig} */
const nextConfig = {
  reactStrictMode: true,
  compiler: {
    removeConsole: process.env.NODE_ENV === 'production',
  },
  webpack: (config) => {
    config.target = ['web', 'es2022'];
    return config;
  },
};

module.exports = nextConfig;
```

Com o ajuste do target para `es2022` e o carregamento dinâmico do formulário de registro, reduzimos as tarefas longas da thread principal de 13 para apenas 5.

import Image from 'next/image';

const DynamicRegistrationForm = dynamic(

### Engenharia de Produção: Caddy HTTP/3, Firewall UFW e Backups no Telegram

Um frontend rápido precisa de infraestrutura sólida. Administramos nossos próprios servidores Linux VPS com padrões rigorosos de segurança:

* **Proxy Reverso Caddy com HTTP/3**: Protocolo QUIC e TLS 1.3 automático garantem tempo de resposta ultra-rápido mesmo em redes móveis instáveis.
* **Defesa Perimetral com UFW e Fail2ban**: Política padrão DROP, liberando estritamente as portas 22, 80 e 443, com bloqueio contínuo contra ataques de força bruta.
* **Backups Criptografados para o Telegram**: Rotinas automatizadas geram dumps compactados e criptografados dos bancos de dados, replicando-os em canais privados seguros como cofre externo.
