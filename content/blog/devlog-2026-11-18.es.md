## Componentes UI: Proyección Cilíndrica 3D con TiltedGridHero

Para elevar el portafolio técnico, adaptamos `TiltedGridHero` en Next.js con Tailwind CSS y TypeScript. La técnica divide cada frame en rebanadas verticales (`preserve-3d`) rotadas levemente sobre el eje Y dentro de un cilindro virtual, manteniendo cero costo de GPU en el thread principal.

![Componente ROI y Métricas](/uploads/devlog/devlog-2026-11-18-component-roi.png)

```tsx
// components/ui/tilted-grid-hero.tsx
```

## Infraestructura de Producción: Linux VPS, Caddy HTTP/3 y Backups a Telegram

El backend opera en un entorno Linux endurecido para resistir tráfico hostil y mantener disponibilidad continua:

1. **Caddy Web Server con HTTP/3 QUIC**: Auto-TLS 1.3 con certificados ZeroSSL/Let's Encrypt y multiplexación UDP en puerto 443.
2. **Firewall Restrictivo UFW**: Tráfico cerrado por defecto, permitiendo únicamente puertos 22 (SSH con llave ed25519), 80 y 443.
3. **Fail2ban**: Jails activas para SSH y autenticación de contenedores Docker.
4. **Disaster Recovery**: Cronjobs que generan snapshots cifrados de PostgreSQL/SQLite y los transmiten mediante el bot de Telegram a una bóveda privada.

```bash
# Hardening y firewall UFW
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443
sudo ufw enable

# Backup automatizado a bóveda de Telegram
DATE=$(date +%Y-%m-%d_%H%M)
BACKUP_FILE="/tmp/db_snapshot_${DATE}.sql.gz"
pg_dump -U postgres -d app_production | gzip > "${BACKUP_FILE}"

curl -F chat_id="${TELEGRAM_ADMIN_VAULT}" \
     -F document=@"${BACKUP_FILE}" \
     -F caption="📦 Snapshot DB Producción - ${DATE}" \
     https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendDocument

rm -f "${BACKUP_FILE}"
```
