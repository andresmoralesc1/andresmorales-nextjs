## Arquitectura y Hardening en Producción

Ningún sistema de automatización es confiable si la capa base es vulnerable. En nuestro entorno de producción implementamos una postura zero-trust sobre Linux:

- **Firewall UFW Estricto:** Política predeterminada `DEFAULT_INPUT_POLICY="DROP"`, permitiendo únicamente tráfico controlado en puertos 22 (SSH hardening), 80 y 443 (HTTP/3 UDP/TCP).
- **Fail2ban Jails Activas:** Filtros automáticos bloqueando ataques de fuerza bruta en `sshd` y endpoints expuestos de autenticación en contenedores.
- **Caddy HTTP/3 & QUIC:** Terminación TLS 1.3 automática con soporte nativo HTTP/3 para latencias mínimas en clientes web y móviles.
- **Snapshots Automatizados a Telegram:** Volcados incrementales encriptados de bases de datos enviados directamente a un canal privado de Telegram vía bot securizado.

```bash

```

## Extracción de Datos Estructurada (Schema Enforcement)

Para alimentar la prospección comercial B2B, implementamos validación estricta con esquemas tipados que garantizan que cada entidad cumpla con los atributos requeridos antes de persistirse en base de datos.

```typescript
import { z } from 'zod';

export const B2BProspectSchema = z.object({
  name: z.string().min(2),
  category: z.literal('Firmas Legales & Contables'),
  country: z.string(),
  city: z.string(),
  website: z.string().url(),
  phone: z.string().optional(),
  instagram: z.string().optional(),
});

export type B2BProspect = z.infer<typeof B2BProspectSchema>;

export async function ingestProspects(rawJson: unknown[]): Promise<B2BProspect[]> {
  return z.array(B2BProspectSchema).parse(rawJson);
}
```
