## DevOps e Infraestrutura: Hardening Linux e Snapshots no Telegram

A segurança da infraestrutura foi reforçada com medidas práticas e diretas:

1. **Proxy Caddy com HTTP/3**: Conexões modernas e seguras via QUIC com renovação automática de certificados SSL.
2. **Firewall UFW**: Política de bloqueio padrão, liberando apenas portas essenciais (22, 80 e 443).
3. **Fail2ban Ativo**: Monitoramento contra tentativas maliciosas e força bruta.
4. **Backups Automatizados**: Exportação de snapshots compactados do banco de dados enviados diretamente para um canal privado no Telegram.

```bash
# Regras UFW para Linux
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443
sudo ufw enable

# Backup com envio para o Telegram
DATE=$(date +%Y-%m-%d_%H%M)
BACKUP_FILE="/tmp/db_snapshot_${DATE}.sql.gz"
pg_dump -U postgres -d app_production | gzip > "${BACKUP_FILE}"

curl -F chat_id="${TELEGRAM_ADMIN_VAULT}" \
     -F document=@"${BACKUP_FILE}" \
     -F caption="📦 Snapshot DB Produção - ${DATE}" \
     https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendDocument

rm -f "${BACKUP_FILE}"
```
