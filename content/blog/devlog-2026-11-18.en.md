## Conversational Intelligence: autoRex + n8n + Calendar Integration

To overcome unreliable SMTP deliveries and streamline inbound workflows, we refined `autoRex`'s deterministic system prompts:

- **No Blind Quotes**: Strictly directs prospects to interactive `/audit` reports or technical calls.
- **Direct Calendar Handshake**: Queries Google Calendar availability in real-time, locking 30-minute technical sessions via Google Meet.

```typescript
// n8n / Edge Function Handler - WhatsApp Lead Qualification
interface WebhookPayload {
  senderPhone: string;

  source: 'whatsapp' | 'webchat';
}

  const sanitizedPhone = payload.senderPhone.replace(/\D/g, '');
  
  const isAuditRequest = /audit|speed|ux/i.test(payload.incomingMessage);
  
  if (isAuditRequest) {

    };

}
```

## DevOps & Security: VPS Hardening, Caddy HTTP/3 and Telegram Snapshots

Production servers require strict perimeter defense and reliable disaster recovery:

1. **Caddy Reverse Proxy**: Automatic TLS 1.3 issuance and native HTTP/3 QUIC transport over UDP.
2. **UFW Rules**: Default inbound deny policy, limiting exposed ports strictly to 22 (SSH), 80, and 443.
3. **Fail2ban Jails**: Continuous log evaluation actively blocking brute-force attempts on SSH and container runtimes.
4. **Automated Telegram Vault**: Encrypted database dumps dispatched off-site via Telegram Bot API.

```bash
# Linux host hardening
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443
sudo ufw enable

# Automated snapshot replication to Telegram
DATE=$(date +%Y-%m-%d_%H%M)
BACKUP_FILE="/tmp/db_snapshot_${DATE}.sql.gz"
pg_dump -U postgres -d app_production | gzip > "${BACKUP_FILE}"

curl -F chat_id="${TELEGRAM_ADMIN_VAULT}" \
     -F document=@"${BACKUP_FILE}" \
     -F caption="📦 Production DB Snapshot - ${DATE}" \
     https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendDocument

rm -f "${BACKUP_FILE}"
```
