## 1. El Reto del Día: Velocidad Técnica y Contexto de Negocio

El sprint de hoy no nació en el vacío; combinó la actualización de infraestructura interna con tres requerimientos de clientes activos de alto impacto:

1. **Latencia de indexación SEO**: Esperar días a que Googlebot rastree sitemaps es inviable tras un despliegue crítico. Necesitábamos automatizar notificaciones push directas hacia la API de Google Indexing y Bing IndexNow inmediatamente tras cada deploy en Vercel/GitHub Actions.
2. **Consultoría sin fricción para Enterprise (Caso Bosi)**: Al auditar marcas consolidadas en plataformas como VTEX IO, proponer migraciones completas genera rechazo por costos operacionales. El enfoque debía evolucionar hacia arquitecturas headless desacopladas (FastStore / Next.js) que optimicen el LCP por debajo de 1 segundo sin tocar el backend transaccional.
3. **Flujos transaccionales y ticketing headless (Caso Qué Nivel Maribel x La Pérgola)**: Modelar la lógica de negocio para venta de tickets de eventos masivos (control de aforo por estatura, validación de accesos con códigos QR dinámicos, pasarela de correos transaccionales con Mailcow y tarifas dinámicas de preventa a $50k / día del evento $60k).

## 2. Decisiones de Arquitectura & UI/UX

Para elevar la tasa de retención técnica sin sacrificar Core Web Vitals, implementé varios componentes clave sobre Next.js App Router:

### A. Terminal Interactiva para Desarrolladores (`<DeveloperTerminalModal />`)
Los directores de ingeniería y CTOs no leen muros de texto; quieren ver logs, dependencias, stacks y comprobar el rigor técnico. Diseñé una terminal Unix emulada accesible vía atajo de teclado (`Ctrl+K` / `⌘K`) o botón flotante, con comandos interactivos como `curl -s /api/stack`, `inspect case-studies` o `run benchmark`.

### B. Simulador de Retorno de Inversión (`<PortfolioRoiCalculator />`)
Para los perfiles directivos y no técnicos, el valor debe cuantificarse. El calculador de ROI interactivo permite modelar horas hombre desperdiciadas en tareas repetitivas, proyectar el ahorro con agentes autónomos y obtener una estimación de payback en semanas.

### C. Bento Selector y Galería Circular Tridimensional
Sustituí las cuadrículas genéricas por un grid dinámico enriquecido (`<PortfolioInteractiveGrid />` y `<CircularGallery />`) que soporta vistas comparativas interactivas antes/después con soporte táctil optimizado para mobile.

![Experiencia de usuario mobile optimizada con viewport seguro para widgets](/uploads/devlog/devlog-2026-11-11-portfolio-mobile.png)

> **Regla de oro de UX móvil aplicada**: Se añadió un padding inferior seguro (`pb-24` / `80px`) en toda la vista mobile para garantizar que los floating action buttons (WhatsApp y selector de agentes) jamás se solapen con el CTA principal de agendamiento.

## 3. Bloques de Código Representativos

### Automatización de Indexación: Google Indexing API v3 + IndexNow

Cada vez que se publica un caso de estudio o artículo técnico, un webhook automatizado autentica mediante Service Account contra la API de Google Indexing para solicitar un rastreo prioritario en milisegundos:

```typescript
// app/api/webhooks/seo-ping/route.ts
import { google } from 'googleapis';
import { NextRequest, NextResponse } from 'next/server';

const jwtClient = new google.auth.JWT(
  process.env.GOOGLE_SERVICE_ACCOUNT_EMAIL,
  undefined,
  process.env.GOOGLE_PRIVATE_KEY?.replace(/\\n/g, '\n'),
  ['https://www.googleapis.com/auth/indexing']
);

export async function POST(req: NextRequest) {
  const secret = req.headers.get('x-revalidation-secret');
  if (secret !== process.env.INDEXING_WEBHOOK_SECRET) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
  }

  const { url, type = 'URL_UPDATED' } = await req.json();

  try {
    await jwtClient.authorize();
    const indexing = google.indexing({ version: 'v3', auth: jwtClient });
    
    const response = await indexing.urlNotifications.publish({
      requestBody: { url, type },
    });

    // Notificación en paralelo hacia el protocolo IndexNow
    await fetch('https://api.indexnow.org/IndexNow', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        host: 'andresmorales.com.co',
        key: process.env.INDEXNOW_KEY,
        keyLocation: 'https://andresmorales.com.co/andresmorales_indexnow_2026.txt',
        urlList: [url],
      }),
    });

    return NextResponse.json({ success: true, timestamp: response.data.urlNotificationMetadata?.latestUpdate?.notifyTime });
  } catch (error: any) {
    return NextResponse.json({ error: error.message }, { status: 500 });
  }
}
```

### Canónicos Estrictos y Redirección 308 en Edge Middleware

Para preservar el 100% del PageRank y consolidar métricas en Search Console, el middleware fuerza una redirección canónica permanente (HTTP 308) eliminando subdominios residuales antes de resolver las rutas multilenguaje:

```typescript
// middleware.ts
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  const hostname = request.headers.get('host') || '';
  
  // Normalización canonical: Forzar apex domain andresmorales.com.co
  if (hostname.startsWith('www.')) {
    const cleanHost = hostname.replace('www.', '');
    const targetUrl = new URL(request.nextUrl.pathname + request.nextUrl.search, `https://${cleanHost}`);
    return NextResponse.redirect(targetUrl, 308);
  }

  return NextResponse.next();
}
```

## 5. Lecciones Aprendidas

1. **La empatía con el stack del cliente supera al dogmatismo técnico**: Al trabajar auditorías de rendimiento para plataformas masivas en VTEX, sugerir "reescribir todo desde cero" rompe cualquier conversación. La propuesta ganadora es desacoplar el frontend mediante arquitecturas headless o micro-frontends, respetando el backend que ya opera la facturación y logística.
2. **SEO técnico programático > Sitemaps pasivos**: Publicar contenido y limitarse a esperar el ciclo de crawl pasivo es ceder ventaja competitiva. El pipeline automatizado mediante Webhooks + Google Indexing API acelera el ciclo de feedback en Search Console de semanas a minutos.
3. **El diseño responsivo no termina en el CSS Grid**: Cuando integras micro-herramientas flotantes (agentes conversacionales, terminales, calculadoras), debes auditar exhaustivamente el mapa de z-index y los viewports táctiles para evitar bloquear las conversiones finales.
